FREQUENTLY ASKED QUESTIONS

Everything You Need to Know

Answers to common questions about installation, API keys, privacy protection, and supported browsers.

How do I get a 100% free API key for Pluto AI? +

You can get a completely free API key directly from Google AI Studio. Visit aistudio.google.com/app/apikey, sign in with any standard Google account, and click "Create API key". Google's free tier provides up to 500 requests per day via gemini-2.5-flash-lite with zero fees and no credit card required.

How do I load my API key and test the connection? +

Open the Pluto AI side panel in your browser, click the ⚙️ Settings icon in the top-right header, select your active provider (e.g. Google Gemini), and paste your key into the API Key input. Then click the "⚡ Test Key" button. Pluto AI sends a lightweight verification ping in ~200ms and displays 🟢 Connected (200 OK). Finally, click "Save Settings" to lock in your configuration.

Where is my API key stored and is it secure? +

Your API key is stored 100% on your local computer in Chrome's sandboxed chrome.storage.local with AES-GCM-256 client-side encryption. Pluto AI is an open, client-side browser extension with zero central telemetry backends. Your key is NEVER sent to Pluto AI developers or any third-party logging service.

Can I use Pluto AI without any API key or payment? +

Yes! In the Settings modal, choose "Demo Simulator" or "Local/Offline Privacy Mode" under Active Provider. In this mode, Pluto AI operates purely locally using simulated heuristics and on-device DOM analysis without making any external API calls or requiring any secret keys.

What should I do if the "Test Connection" button fails? +

If testing your key returns an error (such as HTTP 401 or 403), check the following common issues: (1) Ensure no accidental leading or trailing spaces were copied with the key string. (2) Ensure the provider selected in the dropdown matches the key format (e.g. Google Gemini keys start with AIzaSy, OpenAI keys start with sk-). (3) For Google AI Studio, ensure your Google Cloud project has Generative Language API enabled. (4) If using a corporate VPN or network proxy, make sure outgoing requests to generativelanguage.googleapis.com are not blocked.

How does Pluto AI guarantee zero raw PII leaks? +

Pluto AI implements an on-device Privacy Shield before any data leaves your browser. It uses Luhn checksum verification for credit cards, contextual DOM attribute markers for password fields, and strict regular expressions for emails, phones, Aadhaar, PAN, and identity tokens. Sensitive data is replaced with deterministic hashed tokens (e.g., [REDACTED_CARD_VISA_8812]), and the payload is encrypted using AES-GCM-256 before inference.

Which AI models and providers are supported? +

Pluto AI supports Google Gemini (Gemini 2.5 Flash Lite with 500 free requests per day, Gemini 2.5 Pro), OpenAI (GPT-4o, GPT-4o-mini), Anthropic (Claude 3.5 Sonnet), Groq (Llama 3.3 70B Vision), Mistral AI (Pixtral), DeepSeek (V3/R1), Together AI, xAI Grok, Cohere, custom OpenAI-compatible endpoints (such as local vLLM, Ollama, or LMStudio), and a 100% Offline Simulator mode.

Which browsers are compatible with Pluto AI? +

Pluto AI is built on standard Chromium Manifest V3 Side Panel APIs and works seamlessly across Google Chrome, Microsoft Edge, Brave Browser, Arc Browser, Opera, and Vivaldi.
